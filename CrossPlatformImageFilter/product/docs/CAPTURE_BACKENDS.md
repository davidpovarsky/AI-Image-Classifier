# Capture backends

Regular loopback proxy is the stable baseline. Capture starts only after engine and policy health succeed and stops before engine shutdown. Exact pre-install proxy state is restored transactionally.

The platform trait preserves a future WFP or native NetworkExtension backend without creating a kernel driver now. Conflicting filters must be detected and reported; security software is never evaded. Linux support documents desktop-specific proxy limitations rather than assuming GNOME everywhere.
