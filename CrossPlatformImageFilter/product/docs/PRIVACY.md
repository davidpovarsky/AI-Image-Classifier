# Privacy

All image inference is local. No component uploads image bytes, crops, page contents, browsing URLs, prompt inputs, tensors, or classification events. The control plane stores device identity/public key, policy assignment/acknowledgement, entitlement, support overrides, and administrative audit records only.

Support bundles are allowlist-built and recursively redact URLs, authorization, password hashes, license keys, device/CA private keys, and image-like fields.
